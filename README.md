# Inventario Supermercado - Flutter Web

Aplicación web en Flutter para la gestión de inventario de un supermercado de pequeña superficie. Implementa operaciones CRUD con datos en memoria.

## Tecnologías
- Flutter 3.x (Dart) para web
- Material Design 3

## Estructura del proyecto
- `lib/main.dart` → toda la aplicación en un solo archivo
- `web/index.html` → punto de entrada web

## Funcionalidades
- Ver lista de productos en tabla
- Agregar nuevo producto con validaciones
- Editar producto existente
- Eliminar producto con confirmación

## Cómo ejecutar
1. Instalar Flutter con soporte web
2. Ejecutar: flutter pub get
3. Ejecutar: flutter run -d chrome
